# Deep Learning Newton

A structured, hands-on journey through deep learning — from the fundamentals of neural networks to modern architectures like CNNs, RNNs, and Transformers.

This repository is designed as a practical learning roadmap for understanding deep learning concepts, implementing models in PyTorch, exploring experiments, and building small projects along the way.

## Why this repository?

Deep learning is best learned by combining:

- theory and intuition
- implementation practice
- experimentation with real data
- repeated review of core concepts

This repository brings together that learning flow in one place.

## Topics covered

- Neural networks basics
- Forward and backward propagation
- Loss functions and optimization
- Activation functions
- Gradient descent and optimization tricks
- Convolutional Neural Networks (CNNs)
- Recurrent Neural Networks (RNNs)
- LSTMs and GRUs
- Attention and Transformers
- Transfer learning
- Practical PyTorch workflows
- Experiments and evaluation
- Mini deep learning projects

## Learning path

1. Start with neural network fundamentals
2. Learn how models train and optimize
3. Explore CNNs for image data
4. Study sequence models for text and time-series
5. Understand Transformers and modern attention-based models
6. Implement and experiment in PyTorch
7. Build small projects and reinforce concepts

## Getting started

If you are beginning your deep learning journey, start with the fundamentals first:

- linear algebra basics
- probability and statistics
- calculus and gradients
- Python programming
- NumPy and PyTorch basics

Then move to model-building and experimentation.

## Suggested workflow

```bash
# Example workflow for a Python/PyTorch environment
python -m venv .venv
source .venv/bin/activate  # Linux / macOS
# .venv\Scripts\activate  # Windows

pip install torch torchvision numpy matplotlib
```
